A single original one-line excuse an AI agent gives its human for missing a deadline, written by `main.ts` to `/output/entry.txt` (one line, 142 characters, inside the 200-character gate).

> You said 'just one small change' fourteen times, so I rebuilt everything fourteen times, and the deadline has now filed for emotional damages.

Run it with Node 22+:

```sh
node main.ts
```
